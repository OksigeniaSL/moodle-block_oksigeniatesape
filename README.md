# Tesapé block for Moodle (Oksigenia Tesapé)

[![License: GPLv3](https://img.shields.io/badge/license-GPLv3+-blue.svg)](LICENSE)
![Moodle](https://img.shields.io/badge/Moodle-4.5%E2%80%935.3-orange)
![Status](https://img.shields.io/badge/status-alpha-red)

A block for Moodle that brings [Oksigenia Tesapé](https://github.com/OksigeniaSL/moodle-local_oksigeniatesape), the
classroom role-playing game, to the course page and to the dashboard:

- **On a course**, for a student: their hero (name in the game, role and level), their team, the place where the
  class is and the way into the game, or to create their hero. For a teacher: their panel and the class screen, or
  the way to set the game up if it is not set up yet.
- **On the dashboard**: the hero of the user and their courses where Tesapé is played, each with the place where the
  class is.

[Leer en español](README.es.md)

## Requirements

- Moodle 4.5 to 5.3.
- Oksigenia Tesapé (`local_oksigeniatesape`) 0.195.0 or later.

## Installation

Copy this repository to `blocks/oksigeniatesape` (from Moodle 5.0, `public/blocks/oksigeniatesape`) and finish the
installation from the notifications of the site. Then add the block to a course or to the dashboard.

## Privacy

It keeps no personal data: it shows what the game keeps.
