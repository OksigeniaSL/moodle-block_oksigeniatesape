# Bloque de Tesapé para Moodle (Oksigenia Tesapé)

Un bloque de Moodle que lleva [Oksigenia Tesapé](https://github.com/OksigeniaSL/moodle-local_oksigeniatesape), el
juego de rol para el aula, a la página del curso y al Área personal:

- **En un curso**, para un alumno: su héroe (nombre en el juego, papel y nivel), su equipo, el lugar donde está la
  clase y la entrada al juego, o a crear su héroe. Para un docente: su panel y la pantalla de clase, o el camino para
  configurar el juego si aún no lo está.
- **En el Área personal**: el héroe del usuario y sus cursos donde se juega a Tesapé, cada uno con el lugar donde está
  la clase.

[Read in English](README.md)

## Requisitos

- Moodle 4.5 a 5.3.
- Oksigenia Tesapé (`local_oksigeniatesape`) 0.195.0 o posterior.

## Instalación

Copia este repositorio en `blocks/oksigeniatesape` (desde Moodle 5.0, `public/blocks/oksigeniatesape`) y termina la
instalación desde las notificaciones del sitio. Después, añade el bloque a un curso o al Área personal.

## Privacidad
